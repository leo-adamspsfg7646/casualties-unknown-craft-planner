## About the Planner

Casualties: Unknown Recipe Planner provides an online way to map crafting recipes from *Casualties: Unknown*. Instead of presenting recipe connections as a simple list, the tool lays them out as flowcharts so crafting paths can be examined visually in a browser.

Use it as a reference while tracing components, arranging crafting information, or checking how individual recipes lead into one another. The planner operates independently from the game and is intended for recipe organization rather than game modification.
